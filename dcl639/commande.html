Les commandes

Pour être compatible, le DCL639 reprend les commandes du FT639. Il fonctionne suivant deux modes : le mode Setup ou le mode Actif. À la mise sous tension, le µC est en mode setup.

Les servos que j'utilise ont une position centrale (0°) pour des impulsions d'environ 1,25 mS ; c'est donc cette durée qui est la référence centrale des plages de fonctionnement programmées en fonction des modes de fonctionnement Short pulse et Long pulse :

Commande des servos :

Le mode Actif permet de positionner les servos dans l'une des 256 positions de la plage à l'aide de deux commandes. Chaque servo-moteur reçoit les impulsions et peut être commandé en envoyant successivement deux octets sur la liaison série. Le premier octet contient le numéro du servo et les bits de poids faible du mot de commande (position entre 0 et 255) ; le deuxième octet contient également le numéro du servo et les bits de poids fort du mot de commande. Évidemment, pour être valides, les octets de commande de position doivent contenir le même numéro de servo.

Premier octet0SSSLLLL
Deuxième octet1SSSHHHH

SSS = numéro du servo (0 à 4) ; LLLL = poids faible ; HHHH = poids fort.

Attention, pour le servo n°1, SSS = 000, pour le servo n°2, SSS = 001...

Ainsi, pour envoyer la commande 185 (10111001) au servo n°3 (patte 4 du DCL639), nous aurons :

 Commande binaireCommande décimale
Premier octet 0010 1001 00101001 41
Deuxième octet 1010 1011 10101011 171

Une commande 127 (01111111 = 0°, soit 1,25 mS) au servo n°1 :
