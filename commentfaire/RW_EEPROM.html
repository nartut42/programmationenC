LIRE ET ECRIRE DANS L'EEPROM DES PICs.

La mémoire EEPROM de certains PIC (16F84,16F87x ...) est une mémoire non volatile qui permet entre autre de sauvegarder des données devant être absolument conservées même après une coupure d'alimentation. La gestion de l'espace mémoire est un peu plus délicate que l'espace RAM puisque vous devez penser à quelle adresse mémoire EEPROM vous allez stocker vos données. Ce qui veut dire que vous devrez, pour chaque octet, spécifier une adresse de début qui peut être n'importe où dans la mémoire.

Lors d'une écriture, vous "découperez" vos données en octets (8 bits), chaque octet étant enregistré dans un emplacement mémoire. Lors de la lecture, il faut effectuer l'opération inverse c'est à dire lire les octets et reconstituer les données. Bref, une gestion stricte de la mémoire EEPROM pour éviter d'écraser d'autres données.

Le registre EECON1 (pic16F87x)

EEPGD
      
WRERR
WREN
WR
RD

Pour écrire une donnée, il convient de l'écrire dans EEDATA à l'adresse stockée dans le registre EEADR, mettre le bit EEPGD=0, valider l'écriture WREN=1, désactiver les interruptions (GIE=0),écrire dans le registre EECON2 dans l'ordre les valeurs 55h et AAh, enfin de positionner le bit WR=1. Soit en assembleur:

BSF STATUS, RP1
BCF STATUS, RP0 ; bank2
MOVLW DATA_ADDR ; adresse EEPROM
MOVWF EEADR
MOVLW DONNEE ; Donnee a sauvegarder
MOVWF EEDATA
BSF STATUS, RP0 ; bank3
BCF EECON1, EEPGD ; memoire de donnees
BSF EECON1, WREN

BCF INTCON, GIE
MOVLW 55h
MOVWF EECON2
MOVLW AAh
MOVWF EECON2
BSF EECON1, WR
BSF INTCON, GIE ; si besoin

Pour la lecture c'est un peu plus simple après avoir précisé l'adresse et validé le bit RD, la donnée est présente dans le registre EEDATA:

BSF STATUS, RP1
BCF STATUS, RP0 ; bank2
MOVLW DATA_ADDR ; adresse EEPROM
MOVWF EEADR
BSF STATUS, RP0 ; bank3
BCF EECON1, EEPGD; memoire de donnees
BSF EECON1, RD ; mode lecture
BCF STATUS, RP0 ; bank2
MOVF EEDATA, W ; lecture de la donnee

En langage C, le principe reste le même. Dans l'exemple suivant nous écrirons puis lirons un mot de deux octets (integer) dans l'EEPROM. Le programme teste si les deux octets de la mémoire est vierge (FFFF) à l'adresse 0. Suivant le résultat du test, on lit ou écrit la donnée de deux octets en commencant à l'adresse 0 de la mémoire. Vous retrouverez la même séquence (obligatoire) qu'en assembleur EEPROM_WRITE et EEPROM_READ. Les fonctions d'écrire et de lecture sont ecriture_eeprom(adr,valeur) et lecture_eeprom(adr). Il est possible de regrouper les deux fonctions d'écriture et de lecture qui ont été séparées pour la compréhension de l'exemple.

/*********************************************************************

* http://perso.wanadoo.fr/claude.dreschel/

#include <pic1687x.h>

#define INIT_PORTA TRISA = 0x3F; //PortA = entrees

//Les deux '#define' suivant sont a supprimer s'ils existent déja dans votre <picxxx.h>

// Séquence a executer obligatoirement dans cet ordre

#define EEPROM_WRITE(addr, value) while(WR)continue;EEADR=(addr);EEDATA=(value);EEPGD=0;GIE=0;WREN=1;\
EECON2=0x55;EECON2=0xAA;WR=1;WREN=0
#define EEPROM_READ(addr) ((EEADR=(addr)),(EEPGD=0),(RD=1),EEDATA)

//**************************************************************************
void ecriture_eeprom(unsigned char adr,unsigned int valeur);
unsigned int lecture_eeprom(unsigned char adr);
void init_pic(void);
void eeprom_write(unsigned char addr, unsigned char value);
unsigned char eeprom_read(unsigned char addr);
//*************************************************************************
void main(void)
{
int alarme_tension;
init_pic();

if (lecture_eeprom(0) != 0xFFFF) // EEPROM vierge ?
{

alarme_tension = lecture_eeprom(0); // valeur valide

}else
{
alarme_tension = 120;
ecriture_eeprom (0,alarme_tension);

}

while(!0); // fin du programme
}

//*****************************************************************
void eeprom_write(unsigned char addr, unsigned char value)
{
EEPROM_WRITE (addr, value);
GIE=1; // si besoin
}
unsigned char eeprom_read(unsigned char addr)
{
return (EEPROM_READ(addr));
}
//**************************************************************
void ecriture_eeprom(unsigned char adr,unsigned int valeur)
{
eeprom_write(adr,(unsigned char)valeur);
valeur >> = 8; // decalage de 8 bits a droite
eeprom_write(adr+1,(unsigned char)valeur);
}

unsigned int lecture_eeprom(unsigned char adr)
{
unsigned int temp;
temp=(unsigned char)eeprom_read(adr+1);
temp << = 8; // decalage du poids fort de 8 bits a gauche
temp|=(unsigned char)eeprom_read(adr);
return(temp);
}

//**************************************************************
void init_pic(void)
{
INIT_PORTA;
GIE=1; // si besoin

}
