CREER UNE ENTREE EXTERNE D'INTERRUPTION SUPPLEMENTAIRE

Vous avez déjà utiliser l'entrée RB0 d'un PIC et vous avez besoin d'une autre entrée d'interruption supplémentaire commandée par un front montant ou descendant.

Si le timer0 est disponible, l'astuce consiste à utiliser l'entrée T0CKI du pic sur laquelle vous appliquer le front montant ou descendant de la tension. Par exemple dans le montage "Bat supervisor", l'entrée RB0 est connectée à l'un des boutons poussoir et l'entrée RA4 (T0CKI) au front descendant d'un composant qui surveille la tension d'alimentation. Le front descendant incrémente le compteur qui passe de FF à 00 et génère une interruption qui sauvegarde des variables importantes.

L'entrée RA4 (T0CKI) est configurée en entrée. Ce sera l'entrée d'horloge du timer0 en configurant T0CS=1 pour un front descendant T0SE=1. On valide l'interruption Timer0 par T0IE=1 et enfin on initialise le timer avec la valeur FF et T0IF=0. Tout est prêt, il ne reste plus qu'à autoriser les interruptions GIE=1;

Quand le front descendant (ou montant) survient, la valeur du timer passe de FF à 00. TOIF est positionné à 1 et génère une interruption qui positionne un flag Int_ext et réinitialise le compteur pour le prochain front. Il suffit donc de scruter l'état de Int_ext ou plus simplement de T0IF (sans interruption) et vous venez de créer une deuxième entrée déclenchée par un front montant ou descendant.

Télécharger le programme en C

#include <pic.h>

#define INIT_PORTA TRISA = 0x3F; //T0CKI = entrees

static bit Int_ext;

void interrupt traite_int(void);

void init_pic(void);
//*************************************************************
void main(void)
{
init_pic();
T0IF=0;
GIE=1; // valide interruptions
do
{
if(Int_ext) Int_ext=0;

}while(!0);
}

//*************************************************************
void interrupt traite_int(void)
{

if(T0IF)
{
Int_ext=1;
TMR0=0xFF;
T0IF=0;
}
}
//*************************************************************
void init_pic(void)
{
INIT_PORTA;
T0CS=1; // Entree d'horloge sur T0CKI (RA4)
T0SE=1; // front descendant
T0IE=1; // valide interruption Timer0
TMR0=0xFF; // initialise le compteur à FFh
}
