LIAISON SERIE ASYNCHRONE DES PIC16F87x.

Le PIC16F87X dispose d'une liaison série paramétrable en mode synchrone ou asynchrone (USART). Pour communiquer avec la liaison RS232 d'un PC, il convient de sélectionner le mode asynchrone, la vitesse, le nombre de bits de donnée (8 ou 9). Le 9eme bit étant le bit de parité.

Trois registres permettent de configurer l'USART: TXSTA, RCSTA et SPBRG. Dans l'exemple qui suit nous configurerons l'USART en mode asynchrone à 9600 bauds, 8 bits de données (sans parité).

Donc les bits de TXSTA seront positionnés ainsi: TX9 =0, TXEN=1 (émission valide), SYNC=0 ( mode asynchrone), BRGH = 1 (high speed donc formule Baud rate= Fosc/(16(X+1), X étant la valeur à calculer et à charger dans le registre SPBRG). Pourquoi avoir pris une fréquence de quartz de 11.0592MHz ? Et bien parce que le calcul tombe juste et donc le pourcentage d'erreur est proche de zéro. Bien entendu une autre valeur convient également (voir tableau du datasheet).

Les bits de RCSTA auront pour valeur: SPEN = 1 (port série validé), CREN =1 (valide réception en continu).

Avant d'émettre un octet en écrivant dans TXREG, contrôler l'état du bit TXIF qui doit être à 1 (registre PIR1).Quand le bit RCIF est à 1, un octet a été est reçu dans le registre RCREG.

L'exemple suivant attend un CR (Touche Entrée) avant d'envoyer une chaîne de caractères suivie d'un point.

(Charger ce programme rs_87X.zip)

// Exemple d'émission d'une chaine de caractères et de réception de caractères
// 9600,N,8,1
// Claude Dreschel 2001

#include <pic1687x.h>

/* Frequence du quartz */
#define XTAL 11059200
/* Baud rate */
#define BRATE 9600
#define VALEURBRG (XTAL/16/BRATE)-1
#define CR 0x0D
//*******************************************************************
void init_pic(void);
char getch(void);
void putch(char c);
void put_string(const unsigned char * s);
//*******************************************************************
void main(void)
{

init_pic();
while(getch()!=CR); // attente du caractere retour charriot
put_string("OK RECU UN CR");
putch('.');

while(!0);
}
//********************************************************************
/* fonction init_pic()
*********************************************************************/
void init_pic(void)
{

SYNC=0; //mode asynchrone
SPEN=1; //port série valide
RX9=0; // 8 bits en réception
TX9=0; // 8 bits en emission
CREN=1; //valide reception continue
TXEN=1; // valide emission
BRGH=1; //Bits/s=Fosc/(16(X+1)
SPBRG=VALEURBRG; //9600 bits/s (X=71)
}
//*******************************************************************
/* fonction getch(): lecture d'un caractere sur
la liaison serie.
********************************************************************/
char getch(void)
{
while(!RCIF);
return (RCREG);
}
//*******************************************************************
/* fonction putch(): ecriture dun caractere sur
la liaison serie.
********************************************************************/
void putch(char c)
{
while(!TXIF);
TXREG=c;
}
//*******************************************************************
/* fonction put_string(): ecriture d'une chaine de caracteres
sur la liaison serie.
********************************************************************/
void put_string(const unsigned char * s)
{
while(*s)
putch(*s++);
}
