Variateur de vitesse PWM (PIC16F876)

Variateur de vitesse pour moteur à courant continu commandé en PWM, pour application de radiocommande.

Accueil Présentation Montage Logiciel

Le logiciel

Le programme du microcontrôleur PIC16F876 est bien entendu écrit en langage C ; il tient très largement dans les 4 Ko de sa mémoire de programme. Voyons le fonctionnement des principales fonctions et des registres associés : la mesure de la tension à l'aide du CAN 10 bits, le générateur PWM, et la gestion du temps à l'aide des TIMER0 et 1.

Le convertisseur A/N sur 10 bits

Il est utilisé pour mesurer la tension d'alimentation sur le canal 0 (RA0), la référence de tension étant la tension de 5V régulée par le L7805.

ADFM=1; //mot 10bits justifié à gauche
ADCS1=1; //Fosc/32
ADON=1; // Convertisseur =ON

void mesure(void)
{
unsigned int valeur;

valeur=0;
ADIF=0;
ADGO=1;
while(!ADIF);
valeur = ADRESL;
valeur +=(ADRESH << 8);
if (valeur < 292) //292 pour 1.425V = référence tension seuil alerte tension faible
{
if(nombre_batt_faible++ == 50) tension_faible=1; // compte le nombre mesure batt_ faible successive
led_batt_faible=1;
}
else
{
led_batt_faible=0;
nombre_batt_faible=0;
}
if (led_batt_faible) LED=ON;
else LED=OFF;
}

La fonction mesure() lance le convertisseur A/N afin de mesurer la tension présente sur RA0 (diviseur de tension R9-R10). Le résultat (10 bits) de la conversion est placé dans la variable locale « valeur ». Cette variable est ensuite comparée à la référence 1.425V. La variable de type bit « tension_faible » est positionnée à 1 si, successivement, 50 mesures sont sous le seuil d'alerte, ceci afin de « filtrer » les pics de courant qui pourraient faire chuter la tension de la batterie ponctuellement. Cependant la LED s'allumera au rythme des seuils détectés.

Le générateur PWM

Il est configuré pour les deux sorties PWM, CCP1 et CCP2. La résolution souhaitée, ou le nombre de pas du rapport cyclique, doit être de 8 bits.

Résolution (bits) = log(Fosc/FPWM) / log(2), ce qui donne pour une résolution de 8 bits avec FOSC = 11.0592 MHz : FPWM = 43200 Hz.

La période du signal PWM est calculée ainsi :

PWM (période) = (PR2+1) × 4 × Tosc × (TMR2 valeur prédiviseur), soit pour une fréquence de 11.0592 MHz, un prédiviseur à 1 et PWM (période) = 2.31e-5 s (1/FPWM) : PR2 = 63.

Le rapport cyclique est fixé par la valeur sur 10 bits placée dans CCPRxL et CCPxCON<5:4>, la résolution maximum étant fixée à 8 bits ; il est bien entendu inutile d'y placer des valeurs qui ne seraient pas comprises entre les deux valeurs extrêmes « 0 » et « 255 ». « 0 » donne pour résultat sur les sorties CCP1 et CCP2 une tension en permanence à 0V, et 255 une tension permanente à 5V. Les valeurs intermédiaires font varier le rapport cyclique du signal PWM.

PWM (duty cycle) = (CCPRxL:CCPxCON<5:4>) × Tosc × (TMR2 valeur prédiviseur). Par exemple, la valeur 128 donnera un rapport cyclique de 50%.

void init_PWM(void)
{
PR2=63; //PWM=43.200KHz periode=2,3148e-5S
CCPR1L=0; //Duty cycle =0
CCPR2L=0; //Duty cycle =0
CCP1CON= 0b00001100; //PWM1 mode Duty cycle =0
CCP2CON= 0b00001100; //PWM2 mode Duty cycle =0
TMR2ON=1; // Timer2 =On
}

Le TIMER0 sur 8 bits / 256

Il cadence l'ouverture (8 ms) et la fermeture (12 ms) de la fenêtre de mesure en absence de synchronisation par une impulsion valide. Pour la synchro, le registre TMR0 est chargé pour obtenir 16 ms de temps de fermeture de la fenêtre au début de l'impulsion valide. Ainsi, quelle que soit la durée de l'impulsion, la durée de fermeture de la fenêtre reste constante. « valeur » correspond à la durée de l'impulsion mesurée sur RC3, « 44200 » à environ 16 ms.

void calcul_TMR0(unsigned int valeur)
{
TMR0=256 - (unsigned char)((44200 - valeur) >> 8); // pendant 16ms
tempo_fenetre=0; // ferme la fenetre
}

Le TIMER1 sur 16 bits

Il est utilisé (sous interruption) pour signaler au programme principal que depuis 500 ms il n'y a pas de signal reçu du récepteur.

void interrupt traite_int(void)
{

if(TMR1IF)
{
if(++tempo_pulse == 20) absence_pulse=1; // 1/2 seconde
TMR1IF=0;
}
if(TMR0IF)
{
tempo_fenetre ^= 1;

if(tempo_fenetre)
{
TMR0=169; //8ms
}else TMR0=126; //12ms
TMR0IF=0;
}

}

Le TIMER1 sert également à mesurer la durée des impulsions reçues du récepteur. La mesure d'une impulsion est assez simple à réaliser : il suffit, une fois l'impulsion positive détectée, de démarrer le timer tant que l'impulsion est présente et tant que la fenêtre de mesure est ouverte. Au-delà, l'impulsion n'est pas valide.

unsigned int mesure_pulse(void)
{
unsigned int resultat;

TMR1ON=0;
TMR1H=0;
TMR1L=0;
TMR1ON=1; // Timer1 on
while(RX_PULSE && tempo_fenetre);
TMR1ON=0; //Timer1 Off
resultat=0;
resultat=TMR1H;
resultat <<=8;
resultat |= TMR1L;
if(tempo_fenetre) return(resultat);
else return(0);
}
